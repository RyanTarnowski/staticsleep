
# Static Sleep

I like sleeping to [Brownian noise](https://en.wikipedia.org/wiki/Brownian_noise#). In the past, I used Spotify playlist for this, but Spotify often crashed in the middle of the night, leaving my room eerily quiet...

There are certainly apps I could download, but I figured I would develop my own app specifically for what I wanted.

This was my first time using [Android Studio](https://developer.android.com/studio) and the [Kotlin](https://kotlinlang.org/) language. I did some googling on how to generate Brownian noise and set up a background audio service to play the noise when the phone is locked.

The app is very simple, with only one toggle button. The theme is kept dark to avoid blinding myself at night if I need to turn it off/on.
